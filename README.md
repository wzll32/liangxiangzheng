# 两相争 · 三国战线卡牌对弈

一个单文件网页游戏：真人 vs 电脑，五条战线、两种资源、自动结算。

**在线试玩**：https://liangxiangzheng-ck5cg75mm0v.qoder.zone

## 是什么

- 五条竖线 = 五条战线，每方两条横排（战线 / 本营），每条线每方一格。
- 两种资源：**资源点**（每回合 12 点，抽一个武将 3 点，抽完剩下的自动变成粮草）和**粮草**（武将上场的花销，前线武将每回合要吃 1 张）。
- 核心矛盾：手头的粮草永远不够——你必须在「补新将」和「养老将」之间做选择。
- 玩家不需要操作攻击，只要摆将、喂粮，结算阶段自动开打；红实线是攻击，红虚线是反击。
- 主帅 40 血，先被打空的输；第一回合双方都不出手。

## 怎么跑

直接双击 `index.html` 就行，没有任何依赖、没有构建步骤、不需要联网。

自动自检：在浏览器地址栏后面加 `#selftest`，会跑 300 局 AI 对 AI 并输出结果，例如：

```
SELFTEST OK games=300 avgRounds=8.7 stalls=0
```

## 开发过程

用 [Qoder](https://qoder.com) 分五轮对话完成：

1. 单文件骨架 + 棋盘界面 + 300 局自检
2. 24 名武将、三套技能触发时机（出手时 / 挨打时 / 站着时）
3. 结算动画（箭头、飘字、阵亡淡出、速度切换）
4. 按 3000 局 AI 对 AI 的数据调平衡（双方胜率 52 : 48）
5. Qoder Sites 发布上线

武将全部写在同一张数据表里，新增一个武将只需加一行数据。
